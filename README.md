# Hangman Game 

## About the Project

I created this Hangman game using Python as part of my 100 Days of Code bootcamp. The goal of this project was to practice using loops, conditional statements, lists, and imported modules while building an interactive word-guessing game.

The game randomly selects a word, and the player must guess the correct letters before running out of lives.

## How the Game Works

1. The program randomly selects a word from a list.
2. The word is displayed as underscores to hide the letters.
3. The player guesses one letter at a time.
4. If the letter is correct, it appears in its proper position.
5. If the letter is incorrect, the player loses one life.
6. The player starts with six lives.
7. The game ends when the player guesses the entire word or runs out of lives.

## Python Concepts I Used

- **Random Module:** Randomly selects words from a list.
- **While Loops:** Keeps the game running until the player wins or loses.
- **For Loops:** Checks each letter in the selected word.
- **If/Else Statements:** Determines whether the player's guess is correct.
- **Lists:** Stores correctly guessed letters.
- **Variables:** Tracks the player's lives and progress.
- **String Manipulation:** Updates the hidden word as letters are guessed.
- **Import Statements:** Imports the word list and Hangman artwork from separate Python files.

## How to Run the Game

1. Download or clone this repository.
2. Make sure Python is installed.
3. Keep all three Python files in the same folder.
4. Open the project in PyCharm or another Python editor.
5. Run `main.py`.
6. Start guessing letters to play!
